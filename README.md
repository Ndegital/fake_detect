# 求職者の虚偽回答項目を推定する教師なし学習モデル

求職者のスキル・志向アンケートの中から、**どの項目で「サバを読んでいる」確率が高いか**を、正直な回答（正解データ）なしで推定するアルゴリズムです。
学部4年時に参加した学会発表（電子情報通信学会全国大会、2026/3/10）で用いた研究のコードと資料をまとめています。

🎮 **[Webデモを試す](https://fakedetect-3uu5slsoq24jawcvtck5nk.streamlit.app/)** ／ サンプルデータ:[sample_data.xlsx](https://github.com/user-attachments/files/35281184/sample_data.xlsx)
/📄 [学会発表スライド](https://github.com/user-attachments/files/35281248/default.pdf)

サンプルデータを直接入力していただければすぐに試せます。

## 何を解決するか

IT求人サイトなどでは、求職者が自己申告したスキルをもとに企業がスカウトを行います。しかし自己申告には虚偽が混ざり、ミスマッチの原因になります。

| 既存手法 | 課題 |
|---|---|
| 適性検査（矛盾チェック） | 一貫して嘘をつかれると検出できない |
| Data Shapley / Leave-one-out | データ数に比例して再学習が必要で重く、モデル依存 |
| ノイズ除去（VAE等） | クリーンな教師データが必要で、根拠がブラックボックス |

**本手法は、クリーンデータ不要・一意解・高速・解釈可能**を同時に狙います。

## アイデア

- 観測できるのは、求職者の入力回答 `u`、企業の要求 `v`、企業からのフィードバック `f` のみ。
- 項目ごとに「入力回答 → 真の回答」の遷移確率 `r` を置き、**期待される企業とのマッチ度が、実際のフィードバックと一致する**ように `r` を推定します。
- 項目 k の虚偽確率は `((1 − r_k1) + r_k2) / 2`。
- 企業が公開している要件と真逆の嘘をつく「自滅行為」を抑える項を追加し、ノイズへの頑健性を向上。

目的関数は 二乗誤差 + 対数バリア + 自滅防止項 で構成され、**狭義凸**になるため最適解が一意に定まり、**ニュートン法**で高速に求まります。

## 結果（シミュレーション）

項目数50、マッチング数30,000、1,000回試行。

| フィードバックの条件 | 適合率 | 再現率 | F値 |
|---|---|---|---|
| 理想（コサイン類似度） | 0.96 | 0.94 | 0.95 |
| 高評価/低評価に偏る | 0.97 | 0.90〜0.91 | 0.93 |
| ガウスノイズ付与 | 0.96〜0.97 | 0.83〜0.88 | 0.87〜0.91 |

自滅防止項により、ノイズ下でF値が **6〜15%向上**しました。
