# 求職者の虚偽回答項目を推定する教師なし学習モデル

求職者のスキル・志向アンケートの中から、**どの項目で「サバを読んでいる」確率が高いか**を、正直な回答（正解データ）なしで推定するアルゴリズムである。
学部4年時に参加した学会発表（電子情報通信学会全国大会、2026/3/10）で用いた研究のコードと資料をまとめている。

🎮 **[Webデモを試す](https://fakedetect-3uu5slsoq24jawcvtck5nk.streamlit.app/)** ／ 📊 [サンプルデータ](https://github.com/user-attachments/files/35281184/sample_data.xlsx) ／ 📄 [学会発表スライド](https://github.com/user-attachments/files/35281248/default.pdf)

サンプルデータをデモに直接入力すれば、すぐに試せる。
サンプルデータには、各マッチングごとに次の情報が以下の順で記録されている。

1. 求職者のアンケート回答
2. 企業のアンケート回答
3. 企業のアンケート回答の公開の有無
4. 企業から求職者へのフィードバック

## 何を解決するか

IT求人サイトなどでは、求職者が自己申告したスキルをもとに企業がスカウトを行う。しかし自己申告には虚偽が混ざり、ミスマッチの原因になる。

| 既存手法 | 課題 |
|---|---|
| 適性検査（矛盾チェック） | 一貫して嘘をつかれると検出できない |
| Data Shapley / Leave-one-out | データ数に比例して再学習が必要で重く、モデル依存 |
| ノイズ除去（VAE等） | クリーンな教師データが必要で、根拠がブラックボックス |

**本手法は、クリーンデータ不要・一意解・高速・解釈可能**を同時に狙う。

## アイデア

- 観測できるのは、求職者の入力回答 `u`、企業の要求 `v`、企業からのフィードバック `f` のみである。
- 項目ごとに「入力回答 → 真の回答」の遷移確率 `r` を置き、**期待される企業とのマッチ度が、実際のフィードバックと一致する**ように `r` を推定する。
- 項目 k の虚偽確率は `((1 − r_k1) + r_k2) / 2` と定義する。
- 企業が公開している要件と真逆の嘘をつく「自滅行為」を抑える項を追加した。

目的関数は 二乗誤差 + 対数バリア + 自滅防止項 で構成される。目的関数は**狭義凸**になるため最適解が一意に定まり、**ニュートン法**で高速に求まる。

## 結果（シミュレーション）

項目数50、マッチング数30,000、1,000回試行。

| フィードバックの条件 | 適合率 | 再現率 | F値 |
|---|---|---|---|
| 理想（コサイン類似度） | 0.96 | 0.94 | 0.95 |
| 高評価/低評価に偏る | 0.97 | 0.90〜0.91 | 0.93 |
| ガウスノイズ付与 | 0.96〜0.97 | 0.83〜0.88 | 0.87〜0.91 |

自滅防止項により、ノイズ下でF値が **6〜15%向上**した。

## 使用技術

- Python / NumPy
- 凸最適化（対数バリア法）、ニュートン法

## 今後の課題

本研究では人工データのみを用いたため、実際の採用データに対する有効性の検証は今後の課題である。特に実環境では、5段階評価などの複数選択肢、質問項目間の相関、フィードバックに含まれるノイズが存在する。そのため、これらを考慮したモデルの拡張が必要である。
